# Web-Client mit der Android-App verbunden

Die bisher separat vorbereitete Hintergrundbild-Brücke ist im regulären
[Web-Client](../web/README.md) enthalten. Neue Bilder nutzen nach ausdrücklichem
Speichern `quartinautAppearance`; Altbilder werden nicht automatisch hochgeladen.

Der vollständige Web-Abgleich verwendet die aktuelle Android-Build-33-Basis.
Hosting wird ausschliesslich über `firebase.hosting.json` veröffentlicht.
Prüfungen und Grenzen sind in der Web-Dokumentation festgehalten.
